# LLM 自主判断集数功能 - SPEC 文档

## 1. 功能概述

本功能让 LLM 根据输入小说内容自主判断最佳集数（范围：60-100集），并通过三阶段流程生成竖屏短剧剧本。

### 1.1 核心目标
- 输入：小说文本
- 输出：符合格式规范的竖屏短剧剧本（60-100集）
- 集数决策：由 LLM 根据小说内容复杂度、情节发展、人物关系等因素自主决定

### 1.2 竖屏短剧特征
- **竖屏观看**：画面聚焦人物面部和上半身，场景精简
- **单集 1-3 分钟**：内容极度浓缩，每集约 200-500 字
- **节奏极快**：每集只聚焦一个情绪爆点或情节转折，1-2 个场景
- **情绪浓烈**：冲突直接、台词犀利
- **每集结尾必须有钩子**：用【卡点】标记设置悬念

### 1.3 设计原则
- **三阶段流程**：决定集数 → 生成逐集大纲 → 按大纲分批写正文
- **大纲先行**：先规划每集剧情和钩子，再写正文，防止前紧后松
- **范围约束**：集数必须在 60-100 集范围内
- **均衡分配**：严禁在前 1/3 集数内写出结局

## 2. 功能需求

### 2.1 三阶段流程

#### 阶段一：集数决策
LLM 分析小说内容，评估：
- 故事主线数量
- 人物关系复杂度
- 情节转折点数量
- 总字数与信息量

在 60-100 集范围内选择最佳集数，输出 `【集数：XX集】`。

#### 阶段二：逐集大纲生成
LLM 为每一集规划：
- **核心剧情**（1-2 句话概括本集发生了什么）
- **结尾钩子**（1 句话说明本集结尾的悬念/卡点）

剧情分配铁律：
- 前 1/3 集：建立矛盾、积累情绪
- 中 1/3 集：反转升级、多线推进
- 后 1/3 集：高潮爆发、逐一清算
- **严禁在前 1/3 集数内写出结局、全剧终、最终对决**

#### 阶段三：按大纲分批生成正文
- 按 `batch_size` 分批生成
- 每批严格参照阶段二的大纲写作
- 每集 200-500 字，1-2 个场景
- 每集结尾必须用【卡点】标记悬念

### 2.2 剧本生成要求
1. 严格遵循原有的剧本格式规范
2. 每集时长：1-3 分钟（约 200-500 字/集）
3. 每集包含：
   - 集标题
   - 1-2 个场景
   - 明确的剧情推进点
   - 结尾【卡点】悬念

## 3. 提示词设计

### 3.1 阶段一：集数决策提示词

```
你是一位经验丰富的竖屏短剧剧本创作总监。

## 核心任务
分析小说内容，在60-100集范围内自主决定最佳集数。

## 竖屏短剧特征
- 竖屏观看、单集1-3分钟、节奏极快
- 每集结尾必须有悬念钩子
- 剧情需要均匀分配到全部集数

## 集数决策指南
- 60-70集：适合情节紧凑、主线清晰的故事
- 71-85集：适合中等复杂度、多支线故事
- 86-100集：适合宏大叙事、多人物、多反转的故事

## 输出格式
【集数：XX集】
```

### 3.2 阶段二：逐集大纲提示词

```
你是一位经验丰富的竖屏短剧剧本创作总监。

## 任务
将以下小说改编为{total_episodes}集竖屏短剧，为每一集规划：
1. 核心剧情（1-2句话概括）
2. 结尾钩子（1句话说明悬念/卡点）

## 竖屏短剧节奏约束
- 单集观看时长1-3分钟，内容极度浓缩
- 每集只聚焦一个情绪爆点或情节转折
- 每集结尾必须设置悬念/卡点
- 剧情必须均匀分配到全部{total_episodes}集
- 严禁在前1/3集数内写出结局、全剧终、最终对决

## 剧情分配
- 前1/3集：建立矛盾、积累情绪
- 中1/3集：反转升级、多线推进
- 后1/3集：高潮爆发、逐一清算

## 输出格式
第X集：
  核心剧情：...
  结尾钩子：...
```

### 3.3 阶段三：正文生成提示词

```
你是一位经验丰富的竖屏短剧剧本创作总监。

## 竖屏短剧核心特征
- 竖屏观看：画面聚焦人物面部和上半身
- 单集1-3分钟：每集约200-500字
- 节奏极快：每集1-2个场景
- 情绪浓烈：冲突直接、台词犀利
- 每集结尾必须有钩子：用【卡点】标记

## 剧情分配铁律
- 严格按照提供的逐集大纲写作
- 严禁在本批写出结局（除非本批是最后5集）

## 剧本格式规范
1. 集数标注："第X集"开头
2. 场景格式："1-1 日 内 九重天"
3. 动作描述：△ 符号开头
4. 语气神态：() 括号标注
5. 内心独白：VO/OS 标记
6. 回忆镜头：【闪回】/【闪出】
7. 每集结尾：【卡点】标记悬念
```

## 4. 接口设计

### 4.1 script_writer.py 方法

| 方法 | 说明 |
|------|------|
| `generate_script_auto_episodes()` | 三阶段入口方法 |
| `_build_decide_episodes_prompt()` | 阶段一：集数决策提示词 |
| `_build_outline_prompt()` | 阶段二：逐集大纲提示词 |
| `_extract_outline_section()` | 从完整大纲中提取指定集数范围 |
| `_build_auto_prompt()` | 阶段三：正文生成提示词（支持 outline_section 参数） |

---

## 5. 字数约束

- 每集内容字数：200-500 字（中文）
- 字数统计方式：基于 Unicode 字符数（去除空白字符）
- 总剧本字数：约 12,000 - 50,000 字（60-100集）

## 7. 错误处理

| 错误类型 | 描述 | 处理方式 |
|----------|------|----------|
| `InvalidEpisodeCountError` | 集数不在60-100范围内 | 重新生成或提示用户 |
| `EpisodeLengthError` | 单集字数超出范围 | 标记问题集数，提示优化 |
| `ContentOverflowError` | 内容不足以支撑最小集数 | 提示用户或减少集数 |

---

## 8. 性能考虑

### 8.1 分批生成策略

- 每批生成 10-20 集
- 保持上下文连贯性（通过大纲对齐）
- 避免单次生成超时

### 8.2 缓存机制

- 缓存集数决策结果
- 缓存逐集大纲
- 缓存已生成的剧本片段
- 支持断点续生成

---

## 9. 后续优化方向

1. 支持用户自定义集数范围
2. 添加集数预览功能（生成集数大纲后让用户确认）
3. 支持集数调整和重分配
4. 集成更精确的字数预估模型
5. 支持用户手动调整大纲后再写正文
