## 模块详细输入输出

### 1. config.py

```
输入:
  - 环境变量: DASHSCOPE_API_KEY, OPENAI_API_KEY
  - (可选) .env 文件

输出:
  - Config 对象:
    - api_key: str
    - base_url: str
    - model: str
```

### 2. novel_reader.py

```
输入:
  - file_path: str (小说文件路径)

输出:
  - novel_text: str (小说文本内容)

异常:
  - FileNotFoundError: 文件不存在
  - IOError: 文件读取失败
```

### 3. llm_client.py

```
输入:
  - __init__:
    - api_key: str
    - base_url: str
    - model: str (可选)
  
  - generate():
    - system_prompt: str
    - user_prompt: str

输出:
  - generate():
    - response_text: str (生成的内容)

异常:
  - LLMCallError: API 调用失败
```

### 4. script_writer.py

```
输入:
  - __init__:
    - llm_client: LLMClient
    - template_path: str
  
  - generate_script():
    - novel_text: str
    - output_path: str
    - num_episodes: int (可选)
  
  - generate_script_auto_episodes():
    - novel_text: str
    - output_path: str
    - min_episodes: int (可选)
    - max_episodes: int (可选)

输出:
  - generate_script() / generate_script_auto_episodes():
    - script_content: str (生成的剧本)
    - 保存的文件: <output_path>
```

### 5. format_validator.py

```
输入:
  - validate_script_format():
    - script_content: str
    - template_path: str
  
  - validate_episode_lengths():
    - script_content: str
    - min_chars: int (可选)
    - max_chars: int (可选)

输出:
  - validate_script_format():
    - is_valid: bool
    - issues: list[str]
  
  - validate_episode_lengths():
    - is_valid: bool
    - issues: list[str]
```

## 两种工作模式

### 模式一：指定集数模式

```
命令:
  python src/main.py --novel data/小说.txt --output data/剧本.txt --episodes 5

流程:
  1. 加载配置
  2. 读取小说
  3. 构建提示词 (指定 5 集)
  4. 调用 LLM
  5. 保存剧本
  6. 格式校验
  7. 字数验证
```

### 模式二：自动集数模式

```
命令:
  python src/main.py --novel data/小说.txt --output data/剧本.txt --auto-episodes --min-episodes 60 --max-episodes 100

流程:
  1. 加载配置
  2. 读取小说
  3. 构建提示词 (LLM 自主判断 60-100 集)
  4. 调用 LLM
  5. 保存剧本
  6. 格式校验
  7. 字数验证
```
